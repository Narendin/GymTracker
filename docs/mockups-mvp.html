Мокапы MVP — 23 экрана, сгруппированы по разделам меню

Пять вкладок: Тренировка, Журнал, Мышцы, Изменения, Настройки. Иконки: гантель, календарь, рука с бицепсом (SVG Repo), человечек, шестерёнка. Человечек занят разделом «Изменения». Приложение задаёт четыре группы: «Вид спереди», «Вид сзади», «Вид слева», «Вид справа», пользователь добавляет свои. Долгий тап выделяет фото: при нескольких — кнопки «Сравнить» и «Удалить», при одном — только «Удалить»; дата в левом верхнем углу плитки и снимка, порядок листания — по дате добавления. Комментарии внутри экранов убраны: пояснения только в подписях под мокапами. Слово «завершено» и числа подходов не показываются. Иконка «↻» видна только на последнем завершённом блоке при отсутствии активного упражнения (A3a). Под фото — один текст «Фото», плюс центрируется векторно. В журнале слева число упражнений, справа общий вес.
