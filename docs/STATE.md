# GymTracker — состояние проекта

Приложение по спецификации `docs/gym-tracker-requirements.md` (MVP, релиз 1).
Версия 1.0.0 (`versionCode = 2`). Kotlin + Jetpack Compose + Room, офлайн,
только кг, только русский, тёмная тема по умолчанию.
Изменения по версиям — `docs/CHANGELOG.md`, мокапы — `docs/mockups-mvp.html`,
сборка — `docs/BUILD.md`, выпуск релиза — `docs/RELEASE.md`.

## Как открыть и собрать

1. Открыть папку проекта в Android Studio (File → Open). Gradle wrapper лежит
   в репозитории целиком (`gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`
   и `gradle-wrapper.properties`, Gradle 8.7): он сам скачает дистрибутив,
   устанавливать Gradle не нужно.
2. Создать `secrets.properties` в корне проекта (шаблон — `secrets.properties.example`)
   и указать `applicationId=…`. Идентификатор приложения на телефоне определяется
   им, а не названием; файлы приложения привязаны к нему. Этот файл в `.gitignore`,
   его значение не публикуется.
3. Для подписи релиза добавить в тот же файл `signing.keystore`,
   `signing.storePassword`, `signing.keyAlias`, `signing.keyPassword`. Без них
   релизная сборка остаётся неподписанной.
4. Требуется: JDK 17+, Android SDK API 35.
5. Сборка: `Run app` в Android Studio, либо
   `./gradlew.bat :app:assembleDebug` (debug), `:app:assembleRelease` (релизный APK),
   `:app:test` (юнит-тесты), `:app:signingReport` (отпечатки ключей).

Файл `secrets.properties` читается как UTF-8: свойства по умолчанию читаются в
ISO-8859-1, и кириллица в пути к ключу превращается в недопустимые символы.

## Что реализовано

**Экран A1 («Тренировка», нет активной сессии)** — по мокапу точно:
заголовок, дата сегодня, три счётчика (последняя тренировка / за 30 дней /
всего), акцентная кнопка «Начать тренировку», таб-панель из пяти иконок
(гантель, календарь, рука с бицепсом, человечек, шестерёнка), индикатор активной
вкладки — акцентная линия над иконкой.

Счётчики — кнопки перехода в Журнал (B1), справа шеврон:
- «Последняя тренировка» — детали (B2) этой тренировки; «← Журнал» возвращает
  на A1. Если тренировок нет (значение «—»), строка некликабельна.
- «За 30 дней» — Журнал с фильтром «Месяц» (30 дней — счётчик и фильтр совпадают).
- «Всего тренировок» — Журнал с фильтром «Всё».
«Неделя» и «Год» остаются только в журнале.

**Рабочий цикл записи**
- A2/A3/A3a: сессия, блоки упражнений, bubble-подходы, активный блок раскрыт
  с полями «Повторы»/«Вес» (54 px), вес подставляется из последнего подхода этого
  упражнения — акцентная рамка поля; «↻» только на последнем завершённом блоке
  при отсутствии активного.
- A3b: правка подхода — тап по чипу открывает диалог с полями «Вес» и «Повторы»,
  кнопками «Сохранить», «Удалить», «Отмена». Чипы кликабельны во всех блоках
  текущей сессии, включая свёрнутые завершённые. «Удалить» убирает подход;
  если удалён последний подход блока — показывается A6. Тоннаж пересчитывается
  реакльно (Room-флоу). Журнал прошлых тренировок остаётся read-only.
- A4: выбор упражнения — чипы «Все» (по умолчанию) и шести областей, поиск по
  названию и по мышце, тап возвращает активным блоком. Скрытые упражнения
  («Скрытое» на экране «Мышцы») в список выбора не попадают.
- A5: подтверждение завершения — только при наличии упражнений; пустая сессия
  завершается без подтверждения и не создаёт запись.
- A6: «Подходов нет» — «Завершить без записи» удаляет блок, «Продолжить» оставляет активным.

**Журнал (B1/B2)**
- Chip-фильтр периода (Неделя/Месяц/Год/Всё), список по датам: число упражнений
  и общий вес (Σ вес×повторы).
- Под датой — основные мышцы упражнений тренировки («грудь · широчайшие»),
  порядок по каталогу (область, id), дубли убраны; по ним видно, чем тренировались.
- Детали read-only: блоки с подходами, тап по блоку открывает карточку упражнения.
- Удаление тренировки с подтверждением; подходы в прошлые тренировки не добавляются.
- Правка значения подхода (B2) не реализована: содержимое диалога спецификацией
  не утверждено.

**Мышцы (C1)**
- Аккордеон областей: чипы мышц, упражнения выбранной мышцы, «Добавить упражнение».
- Открытая область и выбранная мышца сохраняются весь запуск приложения: возврат из
  карточки, формы, другой вкладки аккордеон не сворачивает — пользователь видит,
  где произошло изменение. Повторное нажатие на заголовок сворачивает область;
  при запуске приложения всё свёрнуто.
- Иконка глаза справа в строке упражнения: тап скрывает упражнение, иконка
  становится зачёркнутым глазом, упражнение перемещается в блок «Скрытое» своей
  группы. Блок по умолчанию свёрнут, раскрывается по тапу по слову «Скрытое»,
  свёрнут снова, когда скрытых не осталось. Тап по зачёркнутому глазу возвращает
  упражнение в общий список.
- Сортировка по алфавиту в общем списке и в блоке «Скрытое» (`COLLATE NOCASE`).

**Карточка упражнения (C3, C3a)**
- Карточка: фото (тап — лист источника C3a: «Снять фото камерой», «Выбрать из
  галереи», «Удалить фото»), название, мышцы цветом (основные/вторичные), график
  максимального рабочего веса по датам (окно 20 точек, листается свайпом),
  «История упражнения» — тренировки, содержащие это упражнение, тап открывает
  детали тренировки.
- Карандаш в правом верхнем углу открывает форму редактирования.
- «Удалить упражнение» — мягкое удаление с подтверждением: записи журнала, подходы,
  график и история сохраняются; после подтверждения карточка закрывается и происходит
  возврат на прежний экран.

**Форма упражнения (C2, C3c)**
- Название, фото, «Основные мышцы» и «Вторичные мышцы» секциями по мокапу C3c:
  чипы уже выбранных мышц (тап снимает выбор) и чип «+ добавить», открывающий лист
  выбора мышцы; лист показывает мышцы, ещё не выбранные в этой секции.
- Мышца не может быть одновременно основной и вторичной.
- «Сохранить» закрывает форму и возвращает на прежний экран.

**Изменения (E1–E4)**
- Список групп (название, число фото, дата последнего); четыре группы заданы
  приложением («Вид спереди», «Вид сзади», «Вид слева», «Вид справа»), пользователь
  добавляет свои.
- E2: сетка фото по дате добавления (последнее сверху), дата в левом верхнем углу
  плитки; долгий тап выделяет фото.
- Кнопки при выделении, все одного размера и равной ширины: при одном выбранном —
  «Удалить» и «Отменить»; при двух и более — «Сравнить», «Удалить», «Отменить».
  «Добавить» скрыта, пока есть выделение; «Отменить» сбрасывает выделение.
- Удаление фото требует подтверждения: «Вы точно хотите удалить N изображений?»
  (число склоняется).
- «Добавить» — нижний лист источника: камера или галерея; файл копируется в
  `filesDir/photos`.
- E3: просмотр — снимок на весь экран, дата в левом верхнем углу, свайп листает
  по дате добавления; E4: сравнение выделенных фото — лента миниатюр, свайп и тап
  по миниатюре листают, порядок выбора пользователя не влияет.

**Настройки (D1)**
- Тема: тёмная, светлая или как в системе — работает.
- Версия приложения (`BuildConfig.VERSION_NAME`).
- Экспорт, импорт архива, проверка обновлений — серые строки фазы 2.

**Каталог**
- Посев базы: 6 областей, 15 мышц, 46 базовых упражнений с разметкой первичных и
  вторичных мышц. Свой список — открытый вопрос спецификации; каталог редактируется
  в `Seed.kt`, посев выполняется при создании базы.
- Переход базы с версии 1 на 2: поле `isHidden` у упражнения (`MIGRATION_1_2`).

## Решения, заложенные в основу

- Офлайн, никаких разрешений, никаких сетевых обращений.
- Навигация — стек экранов: вкладки добавляются, а не заменяют текущий; вложенные
  экраны (карточка, форма, детали) снимаются, «Назад» возвращает на предыдущее окно;
  двойной «Назад» сворачивает приложение.
- Фото: путь к файлу в `filesDir/photos`, файл копируется при импорте; удаление
  упражнения мягкое (`isDeleted`), записи журнала остаются. Скрытие упражнения —
  поле `isHidden`, оно скрывает упражнение и из списка выбора A4.
- Удаление тренировки каскадно удаляет блоки и подходы; подходы в прошлые
  тренировки не добавляются.
- Идентификатор приложения (`applicationId`) и данные релизного ключа читаются из
  `secrets.properties`, который в `.gitignore`: публичный репозиторий их не раскрывает.
  Отладочную сборку нельзя обновить релизной — ключи разные (проверено по отпечаткам).
- Иконка Мышц: SVG Repo (viewBox 512, залитый путь) — provenance записан в
  `ui/icons/MuscleIcon.kt`.
- Тесты: `./gradlew.bat test` — плюрализация («12 тренировок», «1 тренировка»),
  группировка чисел («1 495 кг»), даты («19 ноября 2026»), посев каталога.
- Автотесты интерфейса (`app/src/androidTest`, `AppFlowTest`) — сквозной прогон
  от пустой базы: старт тренировки, упражнение из каталога, подход, завершение,
  журнал и его фильтры, детали тренировки, счётчики, экран «Мышцы» (аккордеон,
  выбор мышцы, скрытие и возврат упражнения), карточка упражнения (история,
  переход в детали, карандаш, мягкое удаление), форма упражнения (основная
  мышца из «Мышцы», «+ добавить», сохранение), сохранение данных после
  перезапуска, сворачивание двойным «Назад». Элементы находятся по тексту,
  `testTag` и описанию иконки; `testTag` и признак выбранного фильтра
  (`selected`) — часть основного кода. Правку и удаление подходов (issue #6)
  проверяют (p16–p19). Запуск — `docs/BUILD.md`.

## Не реализовано (фазы 2–3)

- Экспорт, импорт, проверка обновлений.
- Правка значения подхода в деталях тренировки.
- Иллюстрации упражнений, виджет, графики за пределами карточки упражнения.
