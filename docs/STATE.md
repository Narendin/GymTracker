# GymTracker — основа приложения

Каркас Android-приложения по спецификации `docs/gym-tracker-requirements.md` (MVP, релиз 1).
Kotlin + Jetpack Compose + Room, офлайн, только кг, только русский, тёмная тема по умолчанию.

## Как открыть и собрать

1. Открыть папку проекта в Android Studio (File → Open). Gradle wrapper лежит
   в репозитории целиком (`gradlew`, `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`
   и `gradle-wrapper.properties`, Gradle 8.7): он сам скачает дистрибутив,
   устанавливать Gradle не нужно.
2. Создать `secrets.properties` в корне проекта (шаблон — `secrets.properties.example`)
   и указать `applicationId=…`. Идентификатор приложения на телефоне определяется
   им, а не названием; файлы приложения привязаны к нему. Этот файл в `.gitignore`,
   его значение не публикуется.
3. Требуется: JDK 17 (Studio поставит сам), Android SDK API 35.
4. Сборка: `Run app` на телефоне/эмуляторе API 26+.
5. Релизные сборки подписывать релизным ключом; отладочные — только на эмулятор
   (правило спецификации: отладочную сборку нельзя обновить релизной).

Сборка на этом компьютере выполняется командой
`./gradlew.bat :app:assembleDebug` с JDK 21 (`JAVA_HOME` указывает на `jbr-21.0.11`);
Gradle 8.7 не работает с Java 25, которую ставит Android Studio.

## Что реализовано

**Экран A1 («Тренировка», нет активной сессии)** — по мокапу точно:
заголовок, дата сегодня, три счётчика (последняя тренировка / за 30 дней /
всего), акцентная кнопка «Начать тренировку», таб-панель из пяти иконок
(гантель, календарь, рука с бицепсом, человечек, шестерёнка), индикатор активной
вкладки — акцентная линия над иконкой.

**Рабочий цикл записи** (ради счётчиков A1 цикл должен работать):
- A2/A3/A3a: сессия, блоки упражнений, bubble-подходы, активный блок раскрыт
  с полями «Повторы»/«Вес» (54 px), вес подставляется из последнего подхода этого
  упражнения — акцентная рамка поля; «↻» только на последнем завершённом блоке
  при отсутствии активного.
- A4: выбор упражнения — чипы «Все» (по умолчанию) и шести областей, поиск по
  названию и по мышце, тап возвращает активным блоком.
- A5: подтверждение завершения — только при наличии упражнений; пустая сессия
  завершается без подтверждения и не создаёт запись.
- A6: «Подходов нет» — «Завершить без записи» удаляет блок, «Продолжить» оставляет активным.

**Журнал (B1/B2)**: chip-фильтр периода (Неделя/Месяц/Год/Всё), список по датам
(дата, число упражнений, общий вес = Σ вес×повторы), детали read-only, удаление
тренировки с подтверждением. Подходы в записанную тренировку не добавляются.

**Мышцы (C1)**: аккордеон областей — при каждом входе на экран все свёрнуты,
повторное нажатие на заголовок сворачивает открытую область; чипы мышц, упражнения
выбранной мышцы,
кнопка «Добавить упражнение» (заглушка).

**Изменения (E1)**: список групп, четыре предустановлены приложением
(«Вид спереди/сзади/слева/справа»), создание своей группы. Просмотр, сравнение,
добавление фото — заглушки.

**Настройки (D1)**: тема (тёмная/светлая/как в системе) работает; Экспорт, Импорт,
Проверка обновлений — серые строки фазы 2; версия приложения.

**Каталог**: посев базы — 6 областей, 15 мышц, 46 базовых упражнений с разметкой
первичных/вторичных мышц. Свой список — открытый вопрос спецификации, каталог
редактируется в `Seed.kt` без миграции.

## Заглушки (следующие шаги)

- C3 карточка упражнения + график; C2/C3c форма создания/редактирования; C3a лист фото.
- Фото упражнений: сущность и каталог `filesDir/photos` готовы, UI съёмки/галереи нет.
- Правка значения подхода (B2) — содержимое диалога не утверждено спецификацией.
- Просмотр/сравнение фото (E2–E4).
- Иллюстрации упражнений, график, виджет — фазы 2–3.

```

  util/        плюрализация, форматирование чисел и дат
  di/          AppContainer — ручной DI без Hilt
  ui/theme/    палитра мокапа: #15171B фон, #2EC4A0 акцент, ...

  ui/icons/    иконка «мышцы» — векторный путь из мокапа (SVG Repo; provenance!)

  ui/history/  Журнал B1/B2
  ui/muscles/  Мышцы C1

  ui/settings/ Настройки D1
app/src/test/  юнит-тесты плюрализации/форматов/посева
```

## Решения, заложенные в основу

- Офлайн, никаких разрешений, никаких сетевых обращений.
- Фото: путь к файлу в `filesDir/photos`, файл копируется при импорте; удаление
  упражнения мягкое (`isDeleted`), записи журнала остаются.
- Удаление тренировки каскадно удаляет блоки и подходы; подходы в прошлые
  тренировки не добавляются.
- Иконка Мышц: SVG Repo (viewBox 512, залитый путь) — provenance записан в
  `ui/icons/MuscleIcon.kt`.
- Тесты: `./gradlew test` — плюрализация («12 тренировок», «1 тренировка»),
  группировка чисел («1 495 кг»), даты («19 ноября 2026»), посев каталога.
