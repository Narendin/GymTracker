# Changelog GymTracker

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [Semantic Versioning](https://semver.org/lang/ru/).
Разделы на версию: `Добавлено`, `Изменено`, `Удалено`. Описание — для пользователя, не по файлам.

## [Unreleased]

### Добавлено

- Иконка «i» — оранжевый контур с оранжевой «i», правый край строки — в раскрытом
  активном блоке упражнения: тап открывает
  лист прошлых тренировок — последние 3 тренировки, содержавшие это упражнение,
  текущая сессия не показывается, свежая сверху. В листе дата, bubble-подходы
  упражнения и его комментарий под чипами; упражнение раньше не выполнялось —
  текст «Данных о прошлых тренировках нет». В свёрнутом блоке иконки нет.
  Оранжевый — новый цвет палитры для информационных действий, используется только
  для иконки «i», акцент остаётся основным. Лист закрывается свайпом, тапом вне
  листа и «Назад», приложение не сворачивается.
- Комментарии к тренировке и к упражнению. Строка комментария тренировки над
  блоками упражнений, комментарий упражнения — под чипами подходов; написанный
  комментарий виден без диалога, пустой показан подсказом «Добавить комментарий».
  Тап по строке открывает диалог: поле с лимитом 250 знаков, счётчик «N / 250»,
  кнопки «Сохранить», «Удалить», «Отмена» — 251-й знак не принимается. Правка
  разрешена в любой момент: в текущей тренировке и в деталях уже записанной
  тренировки; состав подходов остаётся read-only, комментарий — исключение.
  В строке журнала комментарий показывается под датой, обрывается многоточием.
  Удаление тренировки удаляет её комментарии, мягкое удаление упражнения
  записанные комментарии оставляет.

### Изменено

- Дата строки листа истории упражнения — дата тренировки; раньше строка показывала
  «1 января 1970» — в дату попадало не значение тренировки, а её номер.
- Стрелка сворачивания из блоков упражнения убрана: строка блока теперь —
  миниатюра, название и (в активном раскрытом блоке) иконка «i». Раскрытие и
  сворачивание остались по тапу по строке блока. Стрелки убраны и из строк
  «За 30 дней» и «Всего тренировок» главного экрана.
- Завершённые блоки тренировки сворачиваются в одну строку: миниатюра и
  название; подходы и тоннаж в свёрнутом виде не показываются. Тап по строке
  переключает раскрытие блока — bubble-подходы появляются и
  исчезают; несколько блоков можно раскрыть
  одновременно. Иконка
  возобновления «↻» переехала внутрь раскрытого блока (правило A3a сохраняется
  — она только на последнем завершённом блоке при отсутствии активного), из
  сжатой строки она уходит. Активный блок сворачивается тем же тапом по строке, по
  умолчанию он раскрыт. Чипы
  подходов кликабельны в раскрытом блоке.
- Активный блок тренировки сворачивается в ту же однострочную запись, что и
  завершённые: миниатюра и название, акцентная рамка сохраняется — по ней
  видно, что это текущее упражнение. В свёрнутом блоке поля «Повторы» и «Вес»,
  кнопки «Добавить подход» и «Завершить упражнение» и чипы подходов скрыты,
  введенные значения полей сохраняются. По умолчанию активный блок раскрыт;
  добавление подхода раскрытие не меняет, сворачивает только пользователь.
  Чтобы добавить подход в свёрнутом блоке, его сначала разворачивают — кнопки
  видны только в раскрытом виде. Нижние кнопки «Добавить упражнение» и «Завершить
  тренировку» остаются скрытыми, пока есть активный блок, в том числе свёрнутый;
  «↻» не появляется ни на свёрнутых блоках, ни при наличии активного упражнения
  (раньше она показывалась в раскрытом завершённом блоке, когда активный блок
  был на экране). Раскрытие блоков не сохраняется между запусками: при
  восстановлении сессии активный блок раскрыт, завершённые свёрнуты.
  Случайный тап по строке свёрнутого активного блока
  подход не добавляет: строка активного блока переключает раскрытие так же, как
  шеврон, — тот же клик, что и на завершённом блоке, переход в карточку
  упражнения из тренировки убран. «Продолжить упражнение» в диалоге
  «Подходов нет» и возобновление «↻» делают блок активным и раскрывают его.
- Порядок в чипах подходов: повторы слева, вес справа — «5 × 85 кг» вместо
  «85 кг × 5». Единый порядок во всех местах: активный блок тренировки,
  детали тренировки в журнале, история упражнения. Формат собирается одной
  функцией, порядок не разъезжается.

## [1.0.3] — 2026-11-25

### Добавлено

- Проверка обновлений по кнопке: строка «Проверка обновлений» в настройках
  стала активной. По тапу приложение обращается к последней записи релизов на
  GitHub, сравнивает номер версии с текущей и показывает результат: «Версия
  актуальна», «Сеть недоступна» или «Есть версия <номер>» с датой публикации и
  описанием релиза. Из новой версии можно скачать APK: он скачивается во
  внутренний каталог приложения и передаётся системному установщику, журнал и
  настройки при установке сохраняются. Если приложению не разрешено устанавливать
  из себя, диалог ведёт в системные настройки и позволяет повторить установку.
  Подпись строки показывает состояние: номер новой версии, «актуальна»,
  «сеть недоступна», «скачивание…», «не скачалось», «готов», «разрешение».
  Отладочную сборку релизная версия не обновит (ключи подписи разные):
  предупреждение показывается, установку не запускаем. Это единственное сетевое
  обращение приложения: один запрос по нажатию кнопки, без аккаунта, данные
  журнала не передаются.
- Упражнения без дополнительного веса: тоггл «Упражнение без дополнительного веса»
  в форме упражнения (строка под названием), карточка показывает состояние. У такого
  упражнения в тренировке нет поля «Вес», подход добавляется одним значением повторов,
  чип подхода — «12 повт.» вместо «85 кг × 5». В деталях журнала и в истории карточки
  чипы без килограммов; график строится по максимальным повторам. Тоннаж таких
  упражнений не учитывается (0 кг); тренировка только из упражнений без веса
  показывает 0 кг, счётчики тренировок считают её обычной. В каталоге подтягивания,
  брусья, отжимания, выпады, гиперэкстензии, пресс и подобные помечены сразу;
  пользователь переключает тоггл вручную. Записанные подходы при переключении
  тоггла не пересчитываются.
- Правка и удаление подходов в текущей тренировке: тап по чипу подхода открывает
  диалог с полями «Вес» и «Повторы» и кнопками «Сохранить», «Удалить», «Отмена».
  Чипы кликабельны во всех блоках активной сессии, включая свёрнутые завершённые.
  «Удалить» убирает подход; если удалён последний подход блока, показывается
  диалог «Подходов нет». Тоннаж пересчитывается автоматически. Журнал прошлых
  тренировок остаётся без изменений.

### Исправлено

- Кнопки навигации телефона больше не перекрывают нижнюю таб-панель. На
  телефонах с 3-кнопочной навигацией панель целиком видна над кнопками и все
  пять вкладок кликабельны; на телефонах с жестовой навигацией приложение
  занимает весь экран и панель прижата к нижней границе. Поведение одинаково
  на всех экранах, в диалогах и нижних листах; фон продолжается под
  системными кнопками.
- Удаление тренировки из деталей журнала: после подтверждения удаления
  нижняя таб-панель возвращается, пользователь попадает на список журнала
  (или на предыдущий экран, если детали были открыты из карточки упражнения
  или из счётчика «Последняя тренировка»). Кнопка «Назад» после удаления
  возвращает на предыдущий экран одним нажатием.

## [1.0.0] — 2026-11-21

Первый релиз MVP по спецификации (`docs/gym-tracker-requirements.md`, релиз 1).
Приложение работает офлайн, разрешений не требует, русский язык, тёмная тема по умолчанию.

### Добавлено

**Запись тренировки**
- Экран «Тренировка»: дата, три счётчика (последняя тренировка, за 30 дней, всего),
  кнопка «Начать тренировку».
- Сессия: блоки упражнений, подходы в виде «вес кг × повторы», поля «Повторы» и «Вес»,
  вес подставляется из последнего подхода этого упражнения.
- Выбор упражнения: чипы «Все» и шести областей, поиск по названию и по мышце.
- Завершение тренировки с подтверждением, если в сессии есть упражнения; пустая сессия
  завершается без записи.

**Журнал**
- Список записей по датам с фильтром периода (Неделя, Месяц, Год, Всё): число упражнений
  и общий вес.
- Под датой перечислены основные мышцы упражнений тренировки — по ним видно, чем
  тренировались, без входа в детали.
- Детали записи: блоки с подходами, переход в карточку упражнения.
- Удаление тренировки с подтверждением.

**Мышцы**
- Аккордеон областей: чипы мышц, упражнения выбранной мышцы, «Добавить упражнение».
- Упражнение можно скрыть (иконка глаза) — оно перемещается в блок «Скрытое» своей
  группы; блок по умолчанию свёрнут, «Скрытое» раскрывается по тапу по слову.
- Скрытые упражнения исчезают и из списка выбора упражнения при тренировке.
- Упражнения сортируются по алфавиту и в общем списке, и в блоке «Скрытое».
- Открытая область и выбранная мышца сохраняются в рамках запуска приложения:
  возврат из карточки или формы не сворачивает аккордеон, пользователь видит, где
  произошло изменение.

**Карточка и форма упражнения**
- Карточка: фото, мышцы, график максимального рабочего веса по датам, история
  тренировок с этим упражнением, карандаш редактирования, «Удалить упражнение».
- Форма создания и редактирования: название, основные и вторичные мышцы чипами
  с «+ добавить» и листом выбора мышцы; мышца не может быть одновременно основной
  и вторичной.
- Удаление упражнения мягкое: записи тренировок, подходы, график и история
  сохраняются; после подтверждения происходит возврат на прежний экран.

**Фото прогресса**
- Группы сравнения: четыре предустановлены приложением («Вид спереди», «Вид сзади»,
  «Вид слева», «Вид справа»), можно создать свою.
- Снимок камерой и выбор из галереи; дата в левом верхнем углу плитки, порядок
  листания — по дате добавления (последнее сверху).
- Долгий тап выделяет фото; при одном выбранном — «Удалить» и «Отменить», при двух и
  более — «Сравнить». Все кнопки одного размера; «Добавить» скрыта, пока есть выделение.
- Удаление фото требует подтверждения с числом удаляемых снимков:
  «Вы точно хотите удалить N изображений?».
- Экран сравнения: лента миниатюр, снимок на весь экран, свайп и тап по миниатюре.

**Настройки**
- Тема: тёмная, светлая или как в системе. Экспорт, импорт и проверка обновлений
  оставлены как строки второй фазы.
- Версия приложения.

**Каталог**
- Посев базы: 6 областей, 15 мышц, 46 базовых упражнений с разметкой основных
  и вторичных мышц.

**Сборка**
- Идентификатор приложения (`applicationId`) читается из `secrets.properties`
  (файл не попадает в репозиторий), чтобы публичный репозиторий его не раскрывал.
- Подпись релиза читается из `secrets.properties`; без данных ключа релизная сборка
  остаётся неподписанной. Отладочная сборка не обновляется релизной — разные ключи.
- Команда сборки: `./gradlew.bat :app:assembleDebug`, релиза — `:app:assembleRelease`.
